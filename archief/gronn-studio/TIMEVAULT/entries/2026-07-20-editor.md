# 20 Jul 2026 · The studio gets an editor

**Status** verified · **PR** #21 (with #11–#16, not in this history) · **Category** architecture

## Context

Every word on the site lived in TypeScript. The owner could not fix a
typo without a developer — a bad place for a one-person studio.

## Investigation

Where should the words live if not in the code, without adding a service
that has to be paid for, backed up and kept alive?

## Decision

A content document in blob storage, seeded from the typed data in the
code, edited in place on the live site behind a Google sign-in
restricted to one address.

The typed data stays the source of **structure** and the **fallback**,
so the site still builds and renders with no document at all. Nothing
new to log into.

The cost: no editorial workflow, no versioning, no second editor. For
one owner editing their own site, that is the right amount of machinery.

## The path not taken

A Sanity CMS foundation was built alongside this (#10) and never wired
up. It sat dormant for six weeks and was removed on 1 August (#53) as a
dead second content path — two ways to answer "where does this sentence
come from" is one too many.

## Result

The owner edits the live site from a phone. It is still how the words
change today. Structure remains in code and cannot be edited by
accident; prose can be rewritten without touching a repository.
